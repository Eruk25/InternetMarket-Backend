# Руководство пользователя

Приложение «InternetMarket» предназначено для осуществления покупок в интернет-магазине. Пользователь может просматривать каталог товаров, добавлять товары в корзину, оформлять заказы с доставкой, оплачивать заказы и отслеживать их статус.

Для начала работы необходимо зарегистрироваться в системе. На странице регистрации пользователь указывает имя, фамилию, адрес электронной почты и пароль. После заполнения всех обязательных полей необходимо нажать кнопку создания аккаунта. После успешной регистрации пользователю необходимо подтвердить адрес электронной почты.



Рисунок П3.1 – Страница регистрации пользователя

После регистрации пользователь может выполнить вход в систему. На странице входа отображаются поля для ввода адреса электронной почты и пароля. После ввода данных необходимо нажать кнопку «Войти». Если пользователь забыл пароль, он может воспользоваться функцией восстановления доступа.



Рисунок П3.2 – Страница входа в систему

Для восстановления пароля пользователь нажимает ссылку «Забыли пароль?» на странице входа. На странице восстановления необходимо ввести адрес электронной почты, указанный при регистрации. Система отправляет код сброса пароля на указанный email.



Рисунок П3.3 – Страница восстановления пароля

После получения кода сброса пользователь переходит на страницу сброса пароля. Необходимо ввести адрес электронной почты, код сброса из письма и новый пароль с его подтверждением. После успешного сброса пользователь перенаправляется на страницу входа.



Рисунок П3.4 – Страница сброса пароля

При первом входе или после регистрации система проверяет подтверждение адреса электронной почты пользователя. Если электронная почта ещё не подтверждена, отображается окно подтверждения email. Пользователь должен перейти по ссылке из письма, отправленного системой. После успешного подтверждения пользователь получает полный доступ к системе.



Рисунок П3.5 – Модуль подтверждения электронной почты

После успешного входа пользователь попадает на главную страницу интернет-магазина. На ней отображаются приветственный баннер с предложением перейти к каталогу, список категорий товаров и сетка доступных товаров. Сверху расположена панель навигации с ссылками на каталог, корзину, заказы и профиль.



Рисунок П3.6 – Главная страница интернет-магазина

Раздел «Каталог» предназначен для поиска и просмотра товаров. В верхней части страницы расположено поле поиска. Пользователь может ввести название товара, категории или поставщика. Результаты поиска отображаются в виде сетки карточек товаров с изображением, названием, ценой и информацией о наличии на складе.



Рисунок П3.7 – Страница каталога товаров

При нажатии на карточку товара открывается страница с подробным описанием. На странице товара отображаются название, категория, цена, информация о наличии, описание и характеристики: вес, размеры, поставщик и признак крупногабаритности. Пользователь может выбрать количество и добавить товар в корзину.



Рисунок П3.8 – Карточка товара с подробным описанием

Раздел «Корзина» предназначен для управления добавленными товарами. В таблице отображаются товары с названием, ценой за единицу, количеством и общей стоимостью по каждой позиции. Пользователь может изменять количество товаров с помощью кнопок «+» и «−», удалять товары из корзины, а также перейти к оформлению заказа. В боковой панели отображается сводка заказа.



Рисунок П3.9 – Страница корзины

При оформлении заказа пользователь последовательно заполняет контактные данные: ФИО и номер телефона. На странице отображается индикатор этапов оформления для наглядного отслеживания прогресса.



Рисунок П3.10 – Страница оформления заказа (контактные данные)

На следующем этапе пользователь выбирает тип доставки: «Пункт выдачи» или «Курьер». При выборе пункта выдачи необходимо указать город и выбрать подходящий пункт выдачи из списка. При выборе курьерской доставки — указать адрес доставки. Система автоматически рассчитывает стоимость доставки и оценочный срок.



Рисунок П3.11 – Страница оформления заказа (выбор доставки)

После выбора доставки пользователь выбирает способ оплаты: «Карта» или «Наличные». В боковой панели отображается полная сводка заказа: список товаров, стоимость доставки, оценочный срок и итоговая сумма к оплате. После проверки всех данных пользователь нажимает кнопку «Оформить заказ».



Рисунок П3.12 – Страница оформления заказа (выбор оплаты)

Раздел «Заказы» предназначен для просмотра истории заказов пользователя. Для каждого заказа отображаются номер, дата создания, количество позиций, город доставки, текущий статус с цветовой индикацией и общая сумма. В зависимости от статуса доступны действия: оплатить, отменить или подтвердить получение.



Рисунок П3.13 – Страница списка заказов

При нажатии на карточку заказа открывается подробная информация. В карточке заказа отображаются состав заказа (наименования товаров, количество, цена, вес и габариты), общая сумма, контактные данные получателя и доступные действия в зависимости от статуса.



Рисунок П3.14 – Карточка заказа с детальной информацией

Раздел «Профиль» предназначен для управления данными учётной записи пользователя. На странице профиля отображаются информация об аккаунте (имя, фамилия, email, роль), форма редактирования профиля, форма смены email и быстрые ссылки на заказы и каталог.



Рисунок П3.15 – Страница профиля пользователя

Для изменения личных данных пользователь заполняет поля «Имя» и «Фамилия» в форме редактирования профиля и нажимает кнопку «Сохранить». После успешного сохранения отображается сообщение об успешном обновлении профиля.



Рисунок П3.16 – Форма редактирования профиля

Для смены адреса электронной почты пользователь вводит новый email в соответствующем поле и нажимает кнопку «Отправить подтверждение». Система отправляет письмо со ссылкой для подтверждения нового адреса электронной почты.



Рисунок П3.17 – Форма смены email

После перехода по ссылке из письма пользователь попадает на страницу подтверждения email. Система проверяет действительность токена и отображает сообщение об успешной смене email либо об ошибке, если ссылка недействительна.



Рисунок П3.18 – Страница подтверждения email

При подтверждении нового email пользователь перенаправляется в профиль, где отображается обновлённый адрес электронной почты. Система также выписывает новый токен для дальнейшей работы.



Рисунок П3.19 – Страница подтверждения смены email

На странице детального просмотра заказа пользователь может выполнить действия в зависимости от текущего статуса. Для заказа со статусом «Создан» доступны кнопки «Оплатить» и «Отменить заказ». Для заказа со статусом «Оплачен» или «Отправлен» доступна кнопка «Подтвердить получение».



Рисунок П3.20 – Страница заказа с доступными действиями

При нажатии кнопки «Оплатить» система перенаправляет пользователя на страницу платёжного шлюза для ввода платёжных данных. После успешной оплаты пользователь возвращается на страницу заказов, где статус заказа обновляется на «Оплачен».



Рисунок П3.21 – Оплата заказа через платёжный шлюз

Для неавторизованных пользователей доступ к корзине ограничен. При переходе на страницу корзины без авторизации отображается сообщение с предложением войти в систему. После входа корзина становится доступной для просмотра и редактирования.



Рисунок П3.22 – Состояние корзины для неавторизованного пользователя

Если в корзине нет товаров, отображается сообщение «Корзина пуста» с предложением перейти в каталог для выбора товаров. Кнопка «Смотреть товары» перенаправляет пользователя на страницу каталога.



Рисунок П3.23 – Состояние пустой корзины

Если у пользователя нет заказов, на странице заказов отображается сообщение «Заказов пока нет» с предложением перейти в каталог. Кнопка «Смотреть товары» перенаправляет пользователя на страницу каталога.



Рисунок П3.24 – Состояние пустого списка заказов

Для выхода из системы пользователь открывает меню профиля в верхней части страницы и нажимает кнопку «Выйти». В этом же меню доступны инициалы пользователя для быстрого перехода в профиль.



Рисунок П3.25 – Меню профиля

После выхода из системы пользователь перенаправляется на главную страницу. Для повторного входа необходимо нажать кнопку «Войти» в панели навигации и ввести учётные данные.
